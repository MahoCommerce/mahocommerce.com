Maho sells data ownership, so the site must not do that. The woff2 files now live in docs/assets/fonts/ and are served from this origin. All three are variable fonts. Keep them variable: maho.css asks for weight 650 and weight 750 on the largest headings, and static instances cannot render those. Bricolage Grotesque also carries an optical-size axis, which the browser applies on its own through font-optical-sizing. The files are preloaded so the browser starts them during the initial head scan, in parallel with the stylesheets, instead of waiting for layout. This avoids the flash of fallback text (FOUT) that made the nav look like a different font on first load. `crossorigin` is required even though the files are same-origin, because fonts are always fetched in anonymous CORS mode; the preload is discarded and the file downloads twice without it. Only latin and latin-ext are shipped, plus the box-drawing block for Geist Mono (directory trees in the developer docs). There is no Cyrillic or Vietnamese content. `unicode-range` means a subset is downloaded only when a character in it is actually rendered. Both families are SIL Open Font License 1.1.
